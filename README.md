# 🎓 YKS Tercih Robotu & Yerleşme İhtimali Analiz Sistemi

> **20.600+ Resmi ÖSYM / YÖK Atlas programı** üzerinden 5 yıllık taban puan ve sıralama trendlerini analiz eden, adayın net veya sıralamasına göre istatistiksel yerleşme ihtimalini hesaplayan modern web uygulaması.

---

## ✨ Özellikler

- 📊 **20.638 Resmi ÖSYM Programı**: 81 ildeki tüm devlet, vakıf ve KKTC üniversiteleri.
- 📈 **5 Yıllık Gerçek Trend Analizi (2020-2024)**: Resmi ÖSYM taban başarı sıraları, puanları ve 2025 projeksiyonu.
- 🎯 **Akıllı Yerleşme İhtimali Motoru**: Adayın sıralamasına göre %1 - %99 yerleşme ihtimali ve risk kategorileri (*Garanti, İdeal, Dengeli, Riskli, Hayal*).
- 🧮 **TYT & AYT Net ve Puan Hesaplama**: 2024 ÖSYM katsayıları ve OBP (Ortaöğretim Başarı Puanı) desteği.
- 📋 **24'lük ÖSYM Tercih Listesi Yöneticisi**: Liste risk analizi, dengesi ve PDF/Yazdır çıktısı.
- 🌓 **Karanlık / Aydınlık Mod Desteği**: Modern glassmorphism arayüz.

---

## 🛠️ Teknolojiler

- **Frontend**: React 18, TypeScript, Vite
- **Stil & Tasarım**: Tailwind CSS, Lucide Icons, Glassmorphism
- **Grafikler**: Chart.js, react-chartjs-2
- **Efektler**: canvas-confetti

---

## 🚀 Kurulum ve Çalıştırma

```bash
# Bağımlılıkları yükleyin
npm install

# Geliştirme sunucusunu başlatın
npm run dev

# Üretim için derleyin
npm run build
```

Tarayıcınızda `http://localhost:5173` adresine giderek uygulamayı kullanabilirsiniz.
